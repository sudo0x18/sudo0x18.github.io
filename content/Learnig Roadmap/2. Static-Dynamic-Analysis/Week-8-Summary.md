# Week 8: Behavioral Analysis & API Monitoring

**Objective:** Learn to monitor malware behavior in real-time by focusing on API calls.

---

### Day 1: Windows API Review  
- Most commonly abused Windows APIs by malware.  
- Functions related to process creation, file system, registry, and network.

### Day 2: API Hooking Basics  
- How malware hooks APIs to evade detection.  
- Overview of user-mode and kernel-mode hooking.

### Day 3: Using API Monitor Tool  
- Setup and use API Monitor to trace API calls by malware.  
- **Tool:** [API Monitor](http://www.rohitab.com/apimonitor)

### Day 4: Analyzing Suspicious API Calls  
- Identifying malicious behavior via API usage patterns.

### Day 5: Correlate API calls with system changes  
- Cross-reference API call logs with Procmon and Regshot data.

### Day 6-7: Practice API Monitoring  
- Run malware samples while monitoring APIs.  
- Document API call sequences linked to key behaviors.
