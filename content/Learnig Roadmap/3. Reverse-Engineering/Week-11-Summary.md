# Week 11: Deep Dive into Assembly & Advanced Reverse Engineering

**Objective:** Build strong assembly language skills and learn advanced reverse engineering techniques.

---

### Day 1: Review x86/x64 Assembly Instructions  
- Arithmetic, logic, control flow instructions.  
- Differences between 32-bit and 64-bit assembly.

### Day 2: Control Flow & Function Calls  
- Calling conventions (stdcall, cdecl, fastcall).  
- Function prologues/epilogues, stack frames.

### Day 3: Recognizing Common Malware Techniques  
- Code obfuscation, anti-disassembly tricks.  
- Junk code, opaque predicates.

### Day 4: Using IDA Pro & Ghidra for Deeper Analysis  
- Cross-referencing functions, analyzing calls, strings in code.

### Day 5: String Encryption/Decryption in Malware  
- How malware hides strings.  
- Identifying and decrypting strings in assembly.

### Day 6-7: Practice Reverse Engineering  
- Analyze a sample with obfuscated code.  
- Document control flow and decrypted strings.
