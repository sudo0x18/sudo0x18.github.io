# Week 13: Advanced Debugging & Anti-Debugging Techniques

**Objective:** Master debugging malware samples and learn how malware uses anti-debugging tricks.

---

### Day 1: Review Debugging Concepts  
- Breakpoints, stepping, memory inspection refresher.

### Day 2: Common Anti-Debugging Techniques  
- Timing checks, IsDebuggerPresent API, Exception handling tricks.

### Day 3: Bypassing Anti-Debugging  
- Patch or hook anti-debug APIs.  
- Use stealth techniques in x64dbg/OllyDbg.

### Day 4: Kernel Debugging Introduction  
- Overview of kernel debugging concepts and tools.

### Day 5: Using WinDbg for Advanced Debugging  
- Setting up WinDbg, attaching to processes.

### Day 6-7: Practice Debugging Protected Malware  
- Analyze samples with anti-debugging.  
- Document bypass techniques.
