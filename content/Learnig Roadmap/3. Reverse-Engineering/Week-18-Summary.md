# Week 18: Final Project & Continuous Learning

**Objective:** Consolidate learning through a capstone project and plan for continuous skill development.

---

### Day 1-3: Capstone Malware Analysis Project  
- Choose unknown malware sample.  
- Perform full static, dynamic, debugging, memory forensics analysis.

### Day 4: Signature Development  
- Write YARA rules for the sample.  
- Test and refine.

### Day 5: Reporting  
- Create detailed analysis report.

### Day 6-7: Plan Continuous Learning  
- Identify advanced topics to explore (e.g. kernel-level analysis, exploit development).  
- Set learning goals and resources.
