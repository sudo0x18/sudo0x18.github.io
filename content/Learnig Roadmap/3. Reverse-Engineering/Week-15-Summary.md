# Week 15: YARA Rules Fundamentals

**Objective:** Learn how to write YARA rules for malware detection.

---

### Day 1: Introduction to YARA  
- What is YARA and its use cases.

### Day 2: YARA Syntax & Structure  
- Rule components: meta, strings, condition.

### Day 3: Writing Basic YARA Rules  
- Matching strings, hex patterns.

### Day 4: Advanced YARA Features  
- Regular expressions, boolean logic.

### Day 5: Testing YARA Rules  
- Using yara command-line tool to test rules.

### Day 6-7: Practice Writing Rules  
- Write rules for known malware samples.  
- Test and refine them.
