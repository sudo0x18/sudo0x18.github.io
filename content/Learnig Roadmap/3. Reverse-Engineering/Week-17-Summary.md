# Week 17: Threat Hunting & Incident Response with Malware Analysis

**Objective:** Apply malware analysis knowledge in threat hunting and incident response.

---

### Day 1: Threat Hunting Basics  
- Concepts, hypothesis-driven hunting.

### Day 2: Leveraging Malware Analysis in Hunting

### Day 3: Incident Response Workflow  
- Detection, containment, eradication, recovery.

### Day 4: Automating Hunting & Response  
- Using scripts, SIEM integration.

### Day 5: Case Study Analysis  
- Review incident reports, hunting methodologies.

### Day 6-7: Practice Hunting Exercises  
- Hunt on sample datasets.  
- Document process and findings.
