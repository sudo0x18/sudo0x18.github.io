**Objective:** Learn how to quickly triage malware samples and use basic tools for initial analysis.

---

### Day 1: What is Malware Triage?  
- Prioritizing samples, identifying severity and impact.  
- **Resources:**  
  - [Malware Triage overview](https://resources.infosecinstitute.com/topic/malware-triage/)

### Day 2: PEview & File Inspection  
- Understanding PE headers, imports, and metadata.  
- **Tools:**  
  - [PEview](https://www.aldeid.com/wiki/PEview)  
- Practice opening sample binaries and exploring their PE headers.

### Day 3: Using Process Monitor  
- Track file system, registry, and process/thread activity during malware execution.  
- **Practice:** Run Process Monitor with filters to watch sample behavior.

### Day 4: Using Procmon Filters  
- Set filters to capture relevant events only.  
- Save logs and analyze suspicious activity.

### Day 5: Writing Triage Reports  
- Basic format for malware triage reports.  
- Document observed behaviors and suspicious findings.

### Day 6-7: Practice Triage  
- Use public malware samples (e.g., from [MalwareBazaar](https://bazaar.abuse.ch/)) for triage exercises.  
- Create a triage report for one sample.
