# Sysinternals Tools Cheatsheet

## Process Explorer
- View detailed process info, handle and DLL usage

## Process Monitor
- Real-time file, registry, and process/thread activity

## TCPView
- Shows detailed listings of all TCP and UDP endpoints

## Autoruns
- Manage startup programs and services
